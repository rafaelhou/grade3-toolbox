# 三年級工具箱

給小學三年級的線上自學資源：國語、數學、英語、社會、自然，加碼程式與邏輯。
全文附注音，孩子可以自己讀。

**線上瀏覽**
- https://grade3-toolbox.pages.dev/
- https://rafaelhou.github.io/grade3-toolbox/

## 為什麼是三年級

一、二年級的「生活」課是社會、自然、藝術合科；**三年級開始分家**，
多數縣市的英語也從這一年開始，數學進入乘除法與分數。
這是很多孩子第一次感覺到「科目」這件事，也是最適合養成「不會就自己查」習慣的年紀。

## 編輯原則

| 原則 | 說明 |
|---|---|
| 每個連結都實際打開過 | 不是搜尋結果照抄。查證中修掉兩個錯誤的 YouTube 頻道代號，並發現「認識植物」原站已停止維運，改用接手單位的新網址 |
| 能動手的排在影片前面 | 這個年紀看影片容易變成被動接收 |
| 對到課本會上到的東西 | 每一科開頭寫明三年級這一年會碰到什麼 |
| 優先選不用帳號的 | 需要註冊的都標明，沒有必須付費才能用的 |
| 限制照實寫 | 有廣告、要訂閱、介面老舊、內容偏深都寫出來 |
| 中文資源優先 | 八歲要能自己操作，全英文介面會直接卡住 |

## 功能

- **進度追蹤**：點過的資源會打勾，存在瀏覽器的 localStorage，不上傳、不需帳號
- **等級與徽章**：九枚徽章，每一科全開各一枚
- **注音**：全文標注，可關閉。傳統直式排版——符號在字的右側，聲調再靠右，輕聲置頂
- **深色／淺色**：預設跟隨系統，可手動覆蓋
- **純文字網址**：整份清單可直接複製到別的裝置
- **[G3 拼字王](spelling/)**：學校 Spelling Bee 單字表的背誦工具，300 字分 12 組，有發音與拼字練習

### 加資源

只改 `data/resources.js`，其他都會自動跟上（進度總數、徽章、純文字清單、導覽列）。

```js
{ t: '名稱', u: '網址', d: '一句話說明（可用 <b>）',
  lang: '中文', acc: '免費', warn: '選填，限制寫這裡' }
```

`acc` 只要含「需」字，標籤就會變成警示色。

### 注音字庫要同步補

**加了新文案就要補字庫**，否則會變成半標半不標，比完全不標更難讀。
在瀏覽器 console 跑這段找出缺字：

```js
const C = window.ZHUYIN.CHARS; let t = '';
window.SUBJECTS.forEach(s => { t += s.name + s.lead;
  s.groups.forEach(g => { t += g.title + (g.note||'');
    g.items.forEach(i => t += i.t + i.d.replace(/<[^>]+>/g,'') + (i.warn||'')); }); });
document.querySelectorAll('h1,h2,h3,h4,p,li,.bn,.bh').forEach(e => t += e.textContent);
console.log([...new Set([...t].filter(c => /[一-鿿]/.test(c) && !C[c]))].join(''));
```
