# 飲食健康日誌

個人用的飲食與身體紀錄，做成可以加到手機主畫面的網頁 App（PWA）。
跟工具箱的其他內容無關，首頁沒有連結，只是借同一個網站放。

**網址**
- https://grade3-toolbox.pages.dev/diet/
- https://rafaelhou.github.io/grade3-toolbox/diet/

## 裝到 iPhone

1. 用 **Safari** 打開上面的網址
2. 點下方的分享按鈕，往下滑選「加入主畫面」
3. 之後從主畫面的圖示打開：全螢幕、沒有網址列，沒網路也能用

Android 的 Chrome 會直接跳出「安裝」按鈕。

## 功能

| 分頁 | 內容 |
|---|---|
| **今天** | 熱量與蛋白質、碳水、脂肪進度條；早餐、午餐、晚餐、點心四餐；體重、體脂、飲水、睡眠、步數、訓練部位、備註 |
| **趨勢** | 近 7／30 天：平均熱量、平均蛋白質、蛋白質達標天數、體重變化，每日熱量柱狀圖、體重折線圖、數據表 |
| **設定** | 每日目標（預設是 73 kg 維持體重：2,400 大卡／蛋白質 146 g／碳水 315 g／脂肪 62 g）、目標體重、備份匯出與匯入、食物明細 CSV |

- **新增食物**：點「最近吃過」或常見食物一下就記一份，或自己輸入；大卡留空會用 4／4／9 從三大營養素換算
- **資料**：只存在這支手機的 localStorage，不上傳、不需帳號。換手機前在「設定」匯出備份，到新手機匯入
- **離線**：`sw.js` 先給快取版本秒開，背景抓新版，下次打開就是新版
- **深色／淺色**：跟隨系統

## 檔案

```
index.html             頁面骨架、PWA 的 meta
style.css
app.js                 畫面、紀錄、圖表、備份
sw.js                  離線快取
manifest.webmanifest   App 名稱、圖示、全螢幕設定
icon.svg               圖示原檔；三個 PNG 是從它輸出的
apple-touch-icon.png   iPhone 主畫面圖示 180×180
icon-192.png  icon-512.png
```

### 改常見食物

改 `app.js` 開頭的 `FOODS` 陣列，數值是一份的概估：

```js
{ name: '雞胸肉', qty: '150 g', kcal: 170, p: 35, c: 0, f: 3 },
```

### 改了檔案之後

手機上會在**第二次打開**時換成新版（第一次打開時在背景下載）。
新增要離線用的檔案時，記得加進 `sw.js` 的 `ASSETS`。
